# TODOs

Pending work and plans for every project in the monorepo are tracked as
markdown files under `/home/matt/apps/bix-infra/todos/`, not in any tool —
read them with `read_file` like any other file.

- `/home/matt/apps/bix-infra/todos/ALL.md` — compiled view of pending TODOs
  across every project. Start here if asked "what's pending" without a
  specific project named.
- `/home/matt/apps/bix-infra/todos/<project>.md` — one file per project
  (e.g. `bix-ai.md`, `infra.md`) with that project's Pending/Plans/Done
  sections.
- `/home/matt/apps/bix-infra/todos/GUIDE.md` — the file-structure convention,
  read this before writing to a TODO file.

Only read these when the user actually asks about pending work, TODOs, or
plans — not proactively.
